# v49 · 花影绮居 / FLORA SALON · 织花入室

本版按用户反馈，重做花影绮居八个空间、九张视角，替换重复植物挂画与花束，并将方案加入首页精选第 5 位。原工作台方案 ID `silver-retreat` 保持不变，工作台总数仍为 22。

首页顺序：夜廊 → 绒光静邸 → 暮色 → 鞍影织序 → **花影绮居** → 绛天 → 铜绿 → 栖静 → 琥珀曲光 → 山居。

## 设计来源与转译

上一版花影主要来自 GUCCI 的植物色彩与折衷氛围；当时 LOEWE 的工艺方向用于苔织艺邸。本版延续花影的柔绿、奶油白、蜜色木作与少量酒红，进一步参考 LOEWE 对编织、手作和实验性灯具的探索。具体纹样、灯具造型与空间搭配均为本项目生成的原创概念意向，品牌名没有用作方案名或产品背书。

- [LOEWE Weaves](https://www.loewe.com/eur/en/stories-collection/loewe-weaves.html)：编织既可装饰，也可构成物件的结构。
- [LOEWE Lamps](https://www.loewe.com/usa/en/pd/loewe-lamps/loewe-lamps.html)：从不同材料与手工技法理解灯具。

| 空间 | 本版的表达 |
| --- | --- |
| 客厅，两向视角 | 奶油同色玉兰浅浮雕、局部细藤编柜门、低矮马蹄莲与酒红釉陶；取代重复植物画和圆瓶花束 |
| 餐厅 / 玄关 | 编织花瓣灯、原白织物浮雕与细酒红线、空玻璃器物和水果碗 |
| 主卧 | 蕨叶暗纹墙布、花瓣瓷壁灯、侧墙单幅水墨、少量干燥种荚 |
| 次卧 / 书房 | 保留纵向窄床与左侧薄书桌；两幅不同线描、藤编柜面、纸感台灯 |
| 厨房 | 奶油釉面上的灰绿、烟莓抽象拉花；取消装饰挂画与重复花束 |
| 卫生间 | 叶脉釉砖、柔和花瓣轮廓镜、封闭耐水编织感柜面与一枝小花 |
| 景观阳台 | 叶瓣拼嵌小桌、轻藤椅、一株柠檬树，短墙留白 |
| 生活阳台 | 编织感封闭柜面、叶形釉砖腰线、分类篮与清爽整理台 |

所有图片以原 v48 房间图作为编辑目标，保持原窗、墙与紧凑家具关系。反向客厅、餐厅另参考新的客厅图，统一浅浮雕、花瓣灯和柜面。尺寸、构造、耐久与实际施工仍需现场深化；本次不重建 3D。

## 图像与加载

使用 **builtin imagegen**。完整工具提示词、参考图路径与输出路径见 [generation-prompts.json](generation-prompts.json)；交付 WebP 的尺寸、字节和 SHA-256 见 [assets.json](assets.json)。

九张主图均为 1536 × 1024，配九张 480 × 320 缩略图和一张 768 × 512 首页预览，总计 1,795,078 字节。线上采用 `/designs-v49/` 新地址，全部同源；v48 花影旧图留在仓库历史及源素材中，不带入发布包。首页仍按可见卡片加载大图，详情页保留延迟加载、双视角切换和现有材质动效。
