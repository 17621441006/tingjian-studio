# v54 · 经纬结与绛夜弦入室

用户选定第 02 套「经纬结」与第 05 套「绛夜弦」，希望分别融入驿金行邸与首页第一套夜廊。

| 方案 | 满印 | 单枚标志 | 配色 |

图案集中在可替换的软装，不铺满柜墙和地面。经纬结沿用四组交错 N 形与中心留白；绛夜弦保留曲线 N 的轮廓，把紫底改为墨绿/炭灰，与夜廊原有黑白绿金灰衔接。图像为软装概念表达，尚未制作织造/刺绣生产文件。
