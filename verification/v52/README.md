# v52 · 回廊暗纹与花影客厅方案二

本轮调整第 25 套「驿金行邸」与第 5 位精选「花影绮居」。全套仍为 25 套，首页十套精选顺序、布局、加载动画和滑动动效保持。

## 驿金行邸

九张视角覆盖八个空间，全部改为奶油白、干邑皮革、胡桃木与少量古铜。移除旅行箱家具、经典花菱组合、锁扣与铆钉式装饰；使用圆角木柜、普通分格抽屉与帆布分类篮。灵感通过触感、木作收口、缝线与收纳表达。

原创「回廊纹」以错位开放双拱和短针脚形成线纹，用于少量靠包、织物和一段低对比釉砖。床品、柜门、浴室与家务区大部分保持素净。此图案是概念设计，不是可直接加工的精确矢量模板。对应图片为原创住宅概念，不依赖品牌成品采购。

## 花影绮居

核对保留的原客厅实拍后，确认电视柜旁的雕花玻璃是原有装饰元素。本次当前客厅改为弧角蜜木门套、可收拢素纱与清透开口，保留开口位置、梁柱、电视柜、整面餐柜和抽拉餐桌。实际拆改边界与门套、帘轨尺寸仍需现场确认。

「方案二」准确复用 v50 客厅原文件：圆餐桌、矮餐边柜与原屏风，未重新生成或覆盖。入口位于工作台客厅图下方，并同步加入精选空间页；放大、下载及全屋效果册使用对应旧版图。第 23 套花影初版保持原样。

## 资产与提示词

- `generation-prompts.json`：10 次内置 image_gen 编辑的完整提示词、参考与输出路径。
- `assets.json`：21 个 WebP 的尺寸、字节数与哈希。
- `dist/designs-v52/schemes/voyage-atelier/`：九张主图及九张缩略图。
- `dist/designs-v52/schemes/silver-retreat/living.webp`：当前花影客厅；同目录含缩略图。
- `dist/designs-v52/featured/flora-768.webp`：花影首页预览。
- `dist/designs-v50/schemes/silver-retreat/living.webp`：原文件作为方案二。

主图 1536×1024、缩略图 480×320、首屏预览 768×512。Pillow 仅负责等比例导出 WebP；新主图质量参数 78，缩略图 81，首屏预览 84。旧版源图全部保留；发布目录 out 只带使用中的版本。每次由 prepare-hosting.mjs 从源文件原子重建，完整 tar 计入头部与填充后仍需符合平台容量。

## 验证与回退

`baseline.json` 固定首页与其他方案哈希；`rollback/` 保留 v51 四个源模块。`check-v52-refinement.mjs` 验证原始历史图片不变、当前路由、第三按钮的延迟加载、下载与标题同步、取消操作、失败回退及切换竞争；原有集合页、首页动效与隐私检查继续执行。浏览器核对结果见 browser-qa.json。

回退时按需恢复 rollback 源模块与对应资产路由，重建 out 后重新发布；不能直接把旧产物增量覆盖当前发布目录。模型几何未重新生成。本轮没有实测手机 GPU 性能或施工适配。
